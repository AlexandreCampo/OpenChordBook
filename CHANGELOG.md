# Changelog

## 1.12 — public release candidate

- Full-screen offline reader with transposition, chart sizing and day/night themes.
- Chart authoring with previews, named sections, repeat bars and mixed meters.
- Nested library folders and destination selection for imports and authored charts.
- Optional community playlist downloads.
- Export individual charts, selections, folders and the library as iReal Pro HTML.
- Android Save as picker and editable-chart round trips.
- GPL-3.0-or-later license, complete third-party notices and offline About/privacy text.
- OFL music symbols with documented sources and a reproducible font-generation script.
- Android source builds, F-Droid metadata, store screenshots and a standalone web export.
- Organized test suites and repeatable development checks.

Tunes are not packaged; they are downloaded by the user. The first public release has not yet been tagged or published.
